# rdbr_fall_2026

## Setup

Make sure you have `python` and `pip` installed.
```bash
python -V
pip -V
```

Create a virtual environment.
```bash
python venv -m .env
```

Install [fury](https://github.com/fury-gl/fury/tree/master).
```bash
pip install fury
```

## Run

```bash
python src/main.py
```

## Testing

Tests are located in `src/tests'.

```bash
python -m unittest src/tests
```
